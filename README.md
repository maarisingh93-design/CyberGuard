# CyberGuard

Intelligent Network Intrusion Detection and Security Monitoring System.

## Status
Work in progress. Currently in Phase 2: Development environment setup.

## Planned Features
- ML-based detection of normal vs suspicious network traffic (CICIDS2017)
- Flask-based security monitoring dashboard
- SQLite storage for detections and alert history
- Risk scoring and PDF security reports

## Disclaimer
This project is for education and authorized, controlled lab environments only.
The model detects only attack patterns present in its training data and does not
detect all cyberattacks.
